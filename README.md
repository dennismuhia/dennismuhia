# Hi, I'm Dennis Njoroge Muhia 👋

**Software Developer** building algorithmic trading systems and cross-platform mobile products — from Nairobi, Kenya 🇰🇪

I like software that has to be *correct*, not just working: race conditions in trading engines, health-data sync that can't silently drop a step count, deploy pipelines that can't have a 403 on launch day. Currently splitting time between a Go-based algo-trading engine and a Flutter fitness app shipping to Google Play.

---

### 🔭 What I'm building

**[Sentinel](#) — Algorithmic Trading Engine (Go)**
A multi-tenant trading bot trading Deriv synthetic indices (R_10 → R_100) on RSI + Bollinger Band signals, with a Python/Optuna fleet optimizer tuning parameters across a regime-aware search space. Recent work: closing the live-vs-backtest performance gap by fixing signal-to-fill price divergence, a circuit breaker that was writing state nobody read, and goroutine races on proposal IDs — plus a microstructure signal layer (`TickAnalyzer`) sitting in front of the core strategy.

**[SFIT Africa](#) — Fitness Platform (Flutter + Laravel)**
A fitness mobile app with a Laravel backend, registered and operated out of Nairobi. Handles Android Health Connect sync for step/activity data, subscription and checkout flows, and a Laravel API deployed independently to production. Recent work: getting past Google Play's `FOREGROUND_SERVICE` review requirements and fixing a body-map animation bug caused by a curve overshoot producing negative blur radii.
